# Node JS Basic

This project covers the basics of Node JS:

- Run JavaScript using NodeJS
- Use NodeJS modules
- Use specific Node JS module to read files
- Use process to access command line arguments and the environment
- Create a small HTTP server using Node JS
- Create a small HTTP server using Express JS
- Create advanced routes with Express JS
- Use ES6 with Node JS with Babel-node
- Use Nodemon to develop faster

## Files

- `0-console.js` - Display a message to STDOUT
- `1-stdin.js` - Interactive program with stdin
- `2-read_file.js` - Read a file synchronously
- `3-read_file_async.js` - Read a file asynchronously
- `4-http.js` - Small HTTP server with Node
- `5-http.js` - Complex HTTP server with Node
- `6-http_express.js` - Small HTTP server with Express
- `7-http_express.js` - Complex HTTP server with Express
- `full_server/` - Organized HTTP server with Express
